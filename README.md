# Pias Tagebuch 👶

Ein persönliches Tagebuch, um die Entwicklung von **Pia** (* 23.04.2024) festzuhalten –
Fortschritte, Meilensteine, Wutanfälle, schöne Momente und alles dazwischen.

## Aufbau

| Datei / Ordner | Inhalt |
| --- | --- |
| [`meilensteine.md`](meilensteine.md) | Überblick über erreichte Meilensteine (Erstes Lachen, Laufen, erste Wörter …) |
| [`tagebuch/vorlage.md`](tagebuch/vorlage.md) | Vorlage für einen neuen Eintrag zum Kopieren |
| [`tagebuch/lustige-woerter.md`](tagebuch/lustige-woerter.md) | Sammlung von Pias süßen Wort-Verdrehern, Sprüchen & Zitaten 😄 |
| `tagebuch/JAHR/JAHR-MONAT.md` | Die Einträge, nach Monat gebündelt (z. B. `tagebuch/2026/2026-08.md`) |

## Wie ein Eintrag entsteht

Du musst nichts selbst tippen oder formatieren – **beschreib mir einfach, was passiert ist**,
und ich trage es an der richtigen Stelle ein und aktualisiere bei Bedarf die Meilensteine.

Beispiele:
- „Pia hatte heute im Supermarkt einen Wutanfall, weil sie keine Süßigkeiten bekam.“
- „Pia hat heute zum ersten Mal alleine die Treppe hochgekrabbelt.“
- „Sie sagt jetzt ‚Mama‘ und ‚Papa‘ deutlich.“
